# Youths · Астана

Каталог клубов для подростков Астаны. Статический сайт: HTML, CSS и JavaScript, без сервера и без сборки.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Страница сайта |
| `css/styles.css` | Оформление |
| `js/data.js` | **Клубы и секции.** Сюда добавляются новые клубы |
| `js/i18n.js` | Тексты на русском, казахском и английском |
| `js/config.js` | Настройки: адрес сайта, ссылка на Google Форму, почта для жалоб |
| `js/app.js` | Логика сайта |

## Как добавить клуб

1. Откройте сайт, внизу нажмите «+ Панель создателя».
2. Заполните форму, поставьте точку на карте, нажмите «Добавить в каталог».
3. Внизу панели нажмите «Скопировать» у блока «Код для js/data.js».
4. На GitHub откройте `js/data.js` → карандаш (Edit).
5. Вставьте скопированное между `const CLUBS = [` и `];`. Если клубов несколько, между ними нужна запятая.
6. Нажмите «Commit changes». Через 1–2 минуты клуб появится на сайте у всех.

Клуб, добавленный через панель, но не перенесённый в `data.js`, виден только в вашем браузере.

## Настройки (`js/config.js`)

- `siteUrl` — адрес сайта, например `https://username.github.io/`. Нужен для ссылок и QR-кодов.
- `orgFormUrl` — ссылка на Google Форму для организаторов клубов.
- `reportEmail` — почта, куда приходят сообщения «Информация устарела?».

## Проверка на компьютере

Откройте `index.html` двойным кликом, сайт работает без сервера.
