# Youths · Астана

Каталог клубов для подростков Астаны: https://youths-astana.github.io/astana/

Статический сайт: HTML, CSS и JavaScript, без сервера и без сборки. Все файлы лежат рядом, без папок.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Страница сайта |
| `styles.css` | Оформление |
| `communities.json` | **Каталог сообществ.** Этот файл заменяется целиком |
| `data.js` | Список секций и ключевые слова для подсказок |
| `i18n.js` | Тексты на русском, казахском и английском |
| `config.js` | **Настройки сайта** (см. ниже) |
| `app.js` | Логика сайта |

## Как добавить сообщество

1. Откройте панель создателя: адрес сайта плюс `#/add`.
2. Заполните поля, выберите секцию, поставьте точку на карте, нажмите «Добавить в каталог».
3. Внизу панели нажмите **«Скачать communities.json»**. В файле будет и то, что уже на сайте, и всё добавленное в этом браузере.
4. На GitHub откройте `communities.json` → карандаш ✏️ → выделите всё (⌘A) и вставьте содержимое скачанного файла. Либо удалите старый файл и загрузите скачанный через Add file → Upload files.
5. Нажмите «Commit changes». Через 1–2 минуты сообщество появится у всех.

Сообщество, добавленное через панель, но не перенесённое в `communities.json`, видно только в вашем браузере.

**Важно:** переносите каталог с того же устройства, где добавляли сообщества, и начинайте с открытия сайта — панель берёт за основу то, что уже лежит в `communities.json`.

## Фото сообщества

В панели создателя нажмите «Выбрать фото с компьютера». Файл автоматически уменьшается до 1400 px и сжимается, после чего есть два варианта:

1. **«Скачать файл и положить в папку photos»** — рекомендуемый. Файл скачивается, вы загружаете его на GitHub в папку `photos`, а в карточке остаётся короткая ссылка `photos/название.jpg`.
2. **«Встроить фото прямо в код»** — фото попадает внутрь `data.js`. Ничего дополнительно загружать не нужно, но файл растёт на размер фото плюс примерно треть. Обычное фото после сжатия весит 100–300 КБ, поэтому так стоит добавлять два-три сообщества, не больше. Панель сама предупредит, если фото тяжёлое.

Общее правило: держите `data.js` меньше 1 МБ. Когда фото станет много, переносите их в папку `photos` вариантом 1 — размер страницы тогда не зависит от числа сообществ, потому что браузер грузит только те фото, которые открывают.

Ссылки на Google Диск, Instagram и Pinterest не работают: это адреса страниц, а не самих картинок. Прямая ссылка должна заканчиваться на `.jpg`, `.png` или `.webp`.

## Настройки

Настройки меняются в файле `config.js`, а не здесь. Этот README сайт не читает.

- `siteUrl` — адрес сайта. Нужен для ссылок и QR-кодов.
- `orgFormUrl` — ссылка на Google Форму для организаторов клубов.
- `reportEmail` — почта, куда приходят сообщения «Информация устарела?».
- `goatcounter` — код анонимной статистики GoatCounter. Пусто — статистика выключена.
- `creatorLink` — показывать ли ссылку «+ Панель создателя» в подвале. `false` — ссылки нет, панель открывается по адресу `<адрес сайта>#/add`.

Панель создателя открывается по прямой ссылке у любого, кто её знает: на статическом сайте без сервера пароль сделать нельзя. Но чужие добавления сохраняются только в браузере того человека и в каталог не попадают.
