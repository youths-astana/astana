# Telegram-бот Qosyl — как запустить

Бот — один файл `worker.js`. Он берёт каталог прямо с сайта (`communities.json`),
поэтому всё, что появляется на qosyl.club, сразу есть и в боте. Отдельно его
обновлять не нужно.

Запуск бесплатный и займёт около 20 минут. Программировать не нужно,
нужно только копировать и вставлять.

---

## Что умеет бот

**Для подростков** (всё то же, что на сайте):
- 🔎 поиск, который понимает опечатки: «валантер», «дибаты», «бесплатно дебаты»;
- 🧭 направления с фильтрами «Бесплатно», «Новичкам» и выбором района;
- 🎯 подбор за минуту — 5 вопросов, как на сайте;
- 📍 «Рядом со мной» по геолокации (координаты не сохраняются);
- 🎲 «Мне повезёт»;
- карточка сообщества: фото, возраст, цена, расписание, адрес, кнопка WhatsApp
  с готовым первым сообщением, Instagram, Telegram, ссылка на сайт, точка на карте;
- 3 языка: русский, қазақша, English.

**Новое, чего нет на сайте:**
- ⭐ избранное;
- 🔔 подписки на направления: бот сам напишет, когда появится новое сообщество;
- 🗓 подборка из трёх сообществ по воскресеньям (по желанию);
- ⏰ «Напомнить завтра» — бот напомнит написать организатору;
- 💡 «Совет дня» — 12 советов из уроков Qosyl, у каждого есть исследование-источник;
- ↗️ «Позвать друга» — отправить карточку другу в любой чат;
- @бот в любом чате — найти сообщество и сразу отправить его другу (inline-режим);
- ⚠️ «Неточность» — подросток сообщает об ошибке, вам приходит сообщение;
- 🧑‍💼 заявка организатора прямо в боте: 13 вопросов, уходит в ту же Google Форму,
  что и с сайта, а копия приходит вам в Telegram.

**Для вас (администратора):**
- `/stats` — сколько пользователей, подписок, напоминаний;
- `/broadcast текст` — рассылка всем пользователям бота (с предпросмотром);
- `/myid` — узнать свой Telegram ID.

## Шаг 1. Создать бота в Telegram (5 минут)

1. Откройте в Telegram **@BotFather** и отправьте `/newbot`.
2. Имя: `Qosyl — кружки Астаны`.
3. Юзернейм: например `qosyl_club_bot` (должен заканчиваться на `bot`; если занят — придумайте другой).
4. BotFather пришлёт **токен** вида `1234567890:AAH...`. Это пароль от бота: никому его не показывайте.
5. Там же отправьте:
   - `/setinline` → выберите бота → напишите `кружки, дебаты, спорт…` (так заработает поиск через @бот в любом чате);
   - `/setuserpic` → выберите бота → отправьте логотип Qosyl (`icon-512.png` из папки сайта);
   - `/setjoingroups` → выберите бота → `Disable` (боту не нужно сидеть в группах).

## Шаг 2. Cloudflare — бесплатный «дом» для бота (10 минут)

Cloudflare Workers бесплатно держит бота онлайн круглосуточно, банковская карта не нужна.

1. Зарегистрируйтесь на **dash.cloudflare.com** (почта и пароль).
2. Слева откройте **Workers & Pages** → **Create** → **Create Worker** (или «Start with Hello World»).
   Назовите `qosyl-bot` и нажмите **Deploy**.
3. Нажмите **Edit code**. Удалите весь код в редакторе и вставьте содержимое файла
   `bot/worker.js` из репозитория. Удобнее всего открыть его в режиме **Raw** на GitHub,
   выделить всё (Ctrl+A) и скопировать. Нажмите **Deploy**.
4. **Хранилище.** Слева откройте **Storage & Databases → KV** → **Create** → название `qosyl-bot-db`.
   Затем вернитесь в worker `qosyl-bot` → **Settings → Bindings → Add → KV namespace**:
   - Variable name: `DB` (именно так, заглавными);
   - KV namespace: `qosyl-bot-db`.
5. **Настройки.** В worker → **Settings → Variables and Secrets → Add**:

   | Имя | Тип | Значение |
   |---|---|---|
   | `BOT_TOKEN` | Secret | токен от BotFather |
   | `WEBHOOK_SECRET` | Secret | любое длинное слово без пробелов, например `qosyl2026astanaXyZ` |
   | `ADMIN_IDS` | Text | ваш Telegram ID (узнаете на шаге 3, пока можно пропустить) |

6. **Расписание** (уведомления, подборки, напоминания): worker → **Settings → Trigger Events (Triggers)**
   → **Add → Cron Triggers** → впишите `*/10 * * * *` (каждые 10 минут) → **Add**.

## Шаг 3. Включить бота (1 минута)

1. Скопируйте адрес вашего worker. Он показан на его странице, например
   `https://qosyl-bot.ваше-имя.workers.dev`.
2. Откройте в браузере:
   `https://qosyl-bot.ваше-имя.workers.dev/setup?key=ВАШ_WEBHOOK_SECRET`
3. Должна открыться страница, где есть `"webhook": { "ok": true`. Значит, бот подключён.
4. Откройте своего бота в Telegram и нажмите **Start**.
5. Отправьте боту `/myid` → скопируйте число → вставьте его в `ADMIN_IDS` (шаг 2.5) → **Deploy**.
   Теперь вам будут приходить заявки организаторов и сообщения о неточностях, а `/stats` и `/broadcast` заработают.

## Шаг 4. Показать бота на сайте

В файле `config.js` сайта найдите строку `telegramBot: ''` и впишите юзернейм бота без @:

```js
telegramBot: 'qosyl_club_bot',
```

После этого на сайте появятся:
- блок **«У нас есть Telegram-бот!»** на главной и в каталоге, над блоком для организаторов;
- ссылка **«Telegram-бот»** в подвале;
- кнопка **«Открыть в Telegram»** в каждой карточке сообщества.

Пока строка пустая, этих блоков нет, чтобы не вести людей в несуществующего бота.

## Обновить бота

Если поменяли `worker.js`, снова скопируйте его в Cloudflare (**Edit code** → вставить → **Deploy**).
Каталог сообществ обновлять не нужно: бот читает его с сайта сам (кеш 5 минут).

Если на сайте поменялись направления, районы или вопросы Google Формы, выполните:

```bash
node bot/sync-data.mjs
```

Команда вшивает новые данные в `worker.js`. Потом обновите его в Cloudflare.

## Лимиты бесплатного Cloudflare

- 100 000 сообщений боту в день — с запасом.
- 1 000 записей в хранилище в день. Запись происходит, когда человек меняет язык,
  избранное, подписку или проходит заявку. Поиск и просмотр карточек ничего не записывают.
  Если бот станет очень популярным (сотни активных людей каждый день), понадобится
  платный план Workers за $5 в месяц, и лимит вырастет в тысячу раз.
- Рассылки, подборки и уведомления уходят по 40 сообщений каждые 10 минут, то есть до 240 в час.

## Запасной вариант: запустить на своём компьютере

Нужен Node.js 18 или новее. Бот работает, пока включён компьютер.

```bash
cd bot
BOT_TOKEN=ваш_токен ADMIN_IDS=ваш_id node node.js
```

Данные хранятся в `bot/bot-data.json`. Этот файл не попадает в git.
